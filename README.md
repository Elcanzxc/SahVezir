# 3×3: Шахматный обмен фигур (Guarini & Queens Puzzle)

Полноценное десктопное приложение на **Electron**, **React 18**, **TypeScript**, **Tailwind CSS** и **Framer Motion** для визуализации и решения классических шахматных головоломок:
1. **Режим Визирей (Ферзей)** — минимальное решение за **6 ходов**.
2. **Режим Коней (Задача Паоло Гуарини, 1512 г.)** — минимальное решение за **16 ходов**.

---

## 🌟 Новые возможности (UI & UX)
- 🌓 **Темная и Светлая темы:** Переключение одной кнопкой в шапке (с сохранением выбора в `localStorage`).
- 🌐 **Двуязычный интерфейс:** Полная локализация на **русский (RU)** и **английский (EN)** языки.
- ❓ **Теоретическая справка:** Встроенное модальное окно с детальным математическим анализом единственности решений.

---

## 🎯 Правила и цель игры

- **Доска:** 3×3 клетки (`a1`–`c3`).
- **Стартовая позиция:**
  - Белые фигуры: `a1`, `c1` (внизу)
  - Черные фигуры: `a3`, `c3` (вверху)
- **Цель:** Поменять фигуры местами — белые должны переместиться на `a3` и `c3`, а черные — на `a1` и `c1`.
- **Ограничения:**
  - На одной клетке может стоять только одна фигура.
  - Фигуры **не могут рубить** друг друга (ход только на свободную клетку).
  - Ходы совершаются строго по шахматным правилам выбранной фигуры.

---

## ❓ Только ли одно решение у этой задачи?

**Ответ: Нет, решений далеко не одно!**

1. **В режиме Ферзей (6 ходов):**
   - Доска обладает осевой и центральной симметрией.
   - Минимальное решение за 6 ходов можно начать:
     - Слева сверху: `a3 -> b2` (наш базовый авто-ход)
     - Справа сверху: `c3 -> b2` (зеркальное решение)
     - Слева снизу белыми: `a1 -> b2`
     - Справа снизу белыми: `c1 -> b2`
   - Таким образом, существует **как минимум 4 абсолютно симметричных оптимальных решения за 6 ходов**.

2. **В режиме Коней (16 ходов, задача Гуарини):**
   - На доске 3×3 кони не могут попасть на центральную клетку `b2`.
   - Оставшиеся 8 клеток образуют замкнутый **граф-цикл** из 8 вершин:
     $$\text{a1} \to \text{b3} \to \text{c1} \to \text{a2} \to \text{c3} \to \text{b1} \to \text{a3} \to \text{c2} \to \text{a1}$$
   - Двигаться по этому кольцу можно **как по часовой стрелке, так и против часовой стрелки**!
   - Кроме того, внутри каждого из 4 раундов порядок перемещения неколлидирующих коней допускает различные перестановки.

3. **Неоптимальные решения:**
   Если не ограничивать игрока минимальным числом ходов, решений существует **бесконечно много** (за 18, 20, 22 ходов и т.д.).

## 🚀 Команды для запуска

### Быстрый запуск десктопного приложения (Режим разработки)
```bash
npm run start
# или
npm run electron:dev
```

### Сборка и запуск десктопной версии (Production)
```bash
npm run build
npm run electron:build
```

### Запуск только веб-версии (Vite)
```bash
npm run dev
```
